# Business Map

## Purpose

Provide a business-oriented index so a reader can start from the work they want to understand or change without knowing source-code structure.

## Map

Replace the example below with the actual business decomposition.

```text
Business Domain
├─ Process A
│  ├─ Activity A1
│  └─ Activity A2
└─ Process B
   ├─ Activity B1
   └─ Activity B2
```

## Design rule

The terms used here should be the terms business users naturally use. Technical names belong in linked design documents, not as the primary navigation vocabulary.
