# 理解レイヤー

このディレクトリは、人間とAIがシステムを理解するための第一入口です。

目的は、正しいメンタルモデルを短時間で形成し、正本となる詳細情報へ読み手を誘導することです。詳細な要件や設計仕様そのものを重複記載しません。

## ドキュメント

- `system-overview.md` — 目的、利用者、境界、主要フロー
- `business-map.md` — 業務起点のナビゲーション
- `capability-map.md` — 業務ケイパビリティと実装の橋渡し
- `architecture-map.md` — 高水準の技術構造と依存方向
- `change-guide.md` — 変更要求から影響する知識・コードへの逆引き
- `glossary.md` — 標準用語

## 判定基準

読み手が「システムが何をするか」「関心事がどこに属するか」を理解する前に実装詳細を調査しなければならないなら、このレイヤーは不十分です。
