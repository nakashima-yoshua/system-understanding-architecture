# システム概要

## 目的

このシステムが存在する理由と、提供する業務価値を数文で記述します。

## 文脈

システム境界、利用者、外部システム、組織上の位置づけを示します。

## 主要フロー

```text
利用者 / 外部システム → システム → 業務結果
```

## 主要ケイパビリティ

| ID | ケイパビリティ | 目的 | 詳細 |
|---|---|---|---|
| `CAP-EXAMPLE` | 例 | 例となる業務結果を提供する | `capability-map.md` |

## 依存関係

主要な上流・下流システム、データ提供元、運用上の依存関係のみを記述します。

## 変更影響

システム境界や主要責務を変更するときに確認すべき領域を記述します。

## 読解時間の目安

この文書は5〜10分程度でシステム全体のメンタルモデルを形成できる量に保ちます。
