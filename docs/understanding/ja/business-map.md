# 業務マップ

## 目的

ソースコード構造を知らない読み手が、理解または変更したい業務から探索を開始できる業務起点のインデックスを提供します。

## マップ

```text
業務領域
├─ 業務プロセスA
│  ├─ 業務活動A1
│  └─ 業務活動A2
└─ 業務プロセスB
   ├─ 業務活動B1
   └─ 業務活動B2
```

## 対応表

| 業務活動 | Capability ID | 要件 / ユースケース | 実装入口 |
|---|---|---|---|
| 例となる業務 | `CAP-EXAMPLE` | `UC-EXAMPLE-001` | `src/...` |

## 設計ルール

ここでは業務利用者が自然に使う用語を優先します。技術名称は詳細設計へのリンク先で扱います。
