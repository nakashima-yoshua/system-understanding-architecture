# アーキテクチャマップ

## 目的

主要な技術構成要素、依存方向、実行時境界、詳細設計への入口を示します。

## 論理アーキテクチャ

```text
Presentation / Interface
          ↓
Application
          ↓
Domain / Business Rules
          ↓
Infrastructure / Persistence / External Services
```

実際のアーキテクチャに合わせて変更します。実装詳細ではなく、境界と依存方向を伝えることを重視します。
