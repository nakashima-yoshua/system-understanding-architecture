# 変更ガイド

## 目的

「何を変更したいか」から、理解すべき業務・要件・設計・コード・テストへ逆引きするための入口です。

## 変更探索テンプレート

### `<業務上の変更>` を変更したい

1. **ケイパビリティ** — `CAP-...`
2. **業務要件 / ルール** — `BR-...`
3. **機能要件 / ユースケース** — `REQ-...`, `UC-...`
4. **関連ADR** — `ADR-...`
5. **アプリケーション** — `src/...`
6. **DB** — `db/...`
7. **外部インターフェース** — `docs/design/interface/...`
8. **テスト** — `tests/...`
9. **運用 / インフラ** — `infra/...`

## 設計ルール

この文書は詳細仕様を複製しません。変更要求から正本情報へ到達する経路だけを維持します。

変更箇所が分かった後に「なぜそうなっているか」を業務目的やADRまで逆方向に辿れることも必要です。
